# The off-the-shelf software for your business

Shelfware is a collection of ERP software solutions designed for small, local businesses
that don't need all the features, are put off by the complexity, or can't afford commercial versions on the market.

## Key points of Shelfware:

- As easy to deploy as possible
- Minimize the need to install anything external
- Contain manuals explaining how to deploy and use for yourself
- Simple to use: Intuitive design
