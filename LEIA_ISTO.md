# O software pronto para uso para o seu negócio

O Shelfware é um conjunto de soluções de software ERP desenvolvidas para pequenas empresas
que não precisam de todos os recursos, se sentem desmotivadas pela complexidade ou não têm
condições financeiras para adquirir as versões comerciais disponíveis no mercado.

## Pontos chave do Shelfware:

- O mais fácil possível de implementar
- Minimizar a necessidade de recursos externos
- Conter manuais de implementação
- Simples de usar, com design intuitivo
