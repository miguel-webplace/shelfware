# Inventory management software

## Functional requisites
- register product movement
  - in and out
  - prices
  - losses
  - orders
  - categorization
- dashboards
  - comparison between products
  - amount selled at given time
  - KPIs
- types of authorization
  - operator: 
    - in and out, losses
  - manager:
    - new products categorization, prices, orders, dashboards


## Non functional requisites
- friendly interface
- acessible via whatsapp and web

## Technologies
- Docker for containerization
- MySQL for DB
- Sequelize with Node for ORM API
- Astro with Vue for frontend
